HILLCREST DEMO: HOW TO EDIT
1) Photos: see images/README.txt. Add ?labels to any page address to see which photo goes where.
2) WhatsApp number: top of assets/site.js (WHATSAPP).
3) School calendar: edit the EVENTS list in assets/site.js. Dates are YYYY-MM-DD. Past events hide automatically.
4) Fees: edit TUITION and EXTRAS in assets/site.js. Also update the three prices written in fees.html (the extras labels).
5) Everything submits to WhatsApp, so no server is needed. The application is saved on the parent's own device until sent.
